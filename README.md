# Vehicle & Mobility Research — Technische Hochschule Ingolstadt

Public academic project page for a master's research project at **Technische Hochschule Ingolstadt (THI)**.

**Research domain:** Transportation Engineering · Mobility Research · Vehicle Engineering  
**Topic:** Deep-learning-based surrogate modeling of SUMO traffic simulations for route-specific velocity profile prediction
